# **App Name**: DataWise

## Core Features:

- Homepage Design: Home page with clear value proposition and prominent CTAs.
- Service Pages: Service pages detailing each data and AI capability.
- Case Studies Showcase: Case studies section showcasing successful projects and outcomes.
- Contact Form: Contact form for lead capture and inquiry submissions.
- SEO Keyword Generator: AI-powered tool that provides suggested SEO keywords, generated based on uploaded text, to improve page ranking.
- Responsive Layout: Responsive design ensuring optimal viewing experience across devices.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) for a modern and confident feel, reflecting technology and innovation.
- Background color: Light gray (#F0F0F0) for a clean and neutral base.
- Accent color: Soft cyan (#90E0EF) for CTAs and highlights, providing subtle contrast.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral, and objective look. Great for both headlines and body text.
- Use a consistent set of minimalist SVG icons to represent services and data-related concepts.
- Implement a grid-based layout with clear content sections and consistent spacing.
- Use subtle animations and transitions for interactive elements and page loading.
